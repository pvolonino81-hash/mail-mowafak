MAIL MOWAFAK — دليل التشغيل الكامل

مُرسل جماعي عبر SMTP مع تدوير عنوان الخروج — نسخة بيضاء العلامة تخدم عدة عملاء من ملف واحد

الخلاصة في ثلاثة أوامر: 
cd MailRotator
.\tools\Send-Campaign.ps1 -List
.\tools\Send-Campaign.ps1 -ClientId example -RecipientsPath .\data\recipients.example.txt -DryRun
.\tools\Send-Campaign.ps1 -ClientId example -RecipientsPath .\data\recipients.txt

الأمر الأول يعرض العملاء، والثاني يجرّب الحملة بلا إرسال، والثالث يرسلها.

١. كيف يعمل النظام

الميلر برنامج واحد يخدم أكثر من عميل. كل عميل ملف واحد يحدّد اسمه وهويته ورسالته وصندوق مرسّله وحسابات SMTP، ولا يرى المستلم إلا بيانات عميله — لا اسم البرنامج ولا شعاره.

قاعدة العلامة: شعار «موفق» هو شعار البرنامج فقط. يظهر في لوحة التحكم وملفات البرنامج، ولا يظهر أبداً في الرسائل. كل ما يراه المستلم — الاسم، الشعار، البريد، العنوان البريدي — يأتي من ملف العميل.

٢. الخطوة الأولى: ملف العميل

أنشئ مجلد عميل

كل عميل له مجلد داخل clients/:

clients\
  acme\
    client.json      ← بيانات العميل
    message.html     ← رسالته (اختياري)

إن كان العميل لا يحتاج رسالة خاصة، يكفي ملف واحد: clients/acme.json.

املأ ملف client.json

{
  "id": "acme",
  "name": "Acme Store",
  "smtp": {
    "provider": "suddenlink",
    "username": "sender@suddenlink.net",
    "passwordEnv": "OPTONLINE_SMTP_PASSWORD",
    "label": "sb-1"
  },
  "message": {
    "brandName": "Acme Store",
    "logoUrl": "https://your-domain.com/acme-logo.png",
    "fromName": "Acme Store",
    "fromEmail": "sender@suddenlink.net",
    "replyTo": "sender@suddenlink.net",
    "subject": "Hi {{first_name}}, your {{brand_name}} order is ready",
    "templatePath": "message.html",
    "landingUrl": "https://your-domain.com/offer.html",
    "unsubscribeUrl": "https://your-domain.com/unsubscribe.html",
    "listUnsubscribe": "https://your-domain.com/unsubscribe.html",
    "physicalAddress": "Acme Store, 12 Example Street, New York, NY 10001, USA",
    "messageIdHost": "your-domain.com",
    "allowedDomains": ["charter.net", "spectrum.net"]
  }
}
الحقلماذا يحدّد
brandNameالاسم الذي يظهر في الرسالة وفي التقرير
logoUrlرابط شعار العميل داخل الرسالة
fromName / fromEmailاسم المرسّل وصندوقه (يجب أن يطابق حساب SMTP)
templatePathرسالة العميل — تُبحث بجوار ملف العميل أولاً
physicalAddressالعنوان البريدي — إلزامي قانونياً (CAN-SPAM)
allowedDomainsالنطاقات المسموح إرسالها فقط
providerعائلة مزوّد البريد: optimum أو suddenlink أو outlook أو office365 أو auto
passwordEnvاسم متغيّر البيئة الذي يحمل كلمة المرور — لا تُكتب كلمة المرور في الملف أبداً

ضع المتغيّرات في رسالتك

في message.html استخدم هذه الرموز، ويملؤها المحرك لكل مستلم:

{{brand_name}}اسم العلامة
{{first_name}}الاسم الأول
{{name}}الاسم الكامل
{{company}}الشركة (عمود في القائمة)
{{logo_url}}شعار العميل
{{physical_address}}العنوان البريدي
{{tracking_link}}رابط التتبّع
{{unsubscribe_link}}رابط إلغاء الاشتراك

٣. الخطوة الثانية: قائمة المستلمين

القائمة إمّا CSV (كل الأعمدة تعمل كرموز) أو ملف نصي ببساطة:

jane.doe@charter.net,Jane Doe
john.roe@spectrum.net,John Roe
sample.user@neo.rr.com
  • سطر واحد لكل عنوان، والاسم اختياري بعد الفاصلة.
  • الأسطر الفارغة والخطوط التي تبدأ بـ # تُتجاهل.
  • العنوان غير الصالح يُحذف تلقائياً، والمكرَّر يُحتفظ به مرة واحدة.
  • ١٠ آلاف سطر تُحمَّل في أقل من ثانية، والحالة تُحفظ بـ HashSet فلا يتباطأ الفهرس.
ملاحظة أداء: الحفظ يستعمل HashSet بدل قائمة خطية، لذلك البحث عن عنوان داخل ١٠ آلاف سجل يبقى ثابت السرعة بدل أن يُفحص السجل كاملاً في كل رسالة.

٤. الخطوة الثالثة: حسابات SMTP

حساب واحد يكفي، لكن عدّة حسابات تمنع التوقف عند خنق مزوّد لحساب واحد. ضعها في قائمة:

"smtp": {
  "accounts": [
    { "provider": "suddenlink", "username": "one@suddenlink.net", "passwordEnv": "OPTONLINE_SMTP_PASSWORD", "label": "sb-1" },
    { "provider": "suddenlink", "username": "two@suddenlink.net", "passwordEnv": "OPTONLINE_SMTP_PASSWORD", "label": "sb-2" },
    { "provider": "outlook",    "username": "three@outlook.com",  "passwordEnv": "OUTLOOK_SMTP_PASSWORD",  "label": "out-1" }
  ]
}
قاعدة المزوّد: مزوّد Optimum يرفض MAIL FROM إذا لم يطابق الحساب المُصادَق عليه. المحرّك يستخدم عنوان الحساب كمرسل الغلاف تلقائياً، فتبقى الرسالة صالحة دائماً.

٤-ب. البروكسي: استبدال عنوان الخروج

الميلر يخرج عبر بروكسي سكني ويبدّل عنوان الخروج كل ١٥٠ رسالة. ثلاث عائلات مدعومة، والحساب والمضيف والمنفذ وكلمة المرور تأتي منك دائماً:

9Proxyacct-country-us-st-ny-city-nyc-isp-x-sst-10-ssid-<session>
711Proxyacct-zone-custom-region-US-st-Florida-city-Miami-sessTime-5-session-(<session>)
مخصّصنمط تكتبه أنت: {country} {state} {city} {session} {sessionTime}
"proxy": {
  "provider": "711proxy",
  "mode": "gateway",
  "host": "gate.711proxy.com",
  "port": 12345,
  "usernameTemplate": "your-sub-account",
  "passwordEnv": "SEVEN11PROXY_PASSWORD",
  "country": "us",
  "state": "Florida",
  "city": "Miami",
  "sessionTimeMinutes": 5,
  "rotationEvery": 150
}

قبل الحملة افحص البوابة وتأكّد أن العناوين تتبدّل فعلاً:

.\tools\Test-Proxy.ps1 -ClientId example -Count 3
الوضعماذا يعني
gatewayمضيف ومنفذ ثابتان، وتبديل عنوان الخروج برمز الجلسة داخل اسم المستخدم
portsمضيف واحد وقائمة منافذ، كل منفذ = عنوان خروج مختلف (711Proxy By Port)
localتطبيق 9Proxy على سطح المكتب يوجّه عنواناً سكنياً إلى 127.0.0.1
noneبلا بروكسي — الإرسال بعنوان الجهاز

اسم المتغيّر الذي يحمل كلمة المرور يحدّده المزوّد تلقائياً: NINEPROXY_PASSWORD لـ9Proxy وSEVEN11PROXY_PASSWORD لـ711Proxy، ويمكنك تجاوزه في الملف.

السؤال عن كلمة المرور يظهر بمصفوف مخفي، وتبقى في ذاكرة العملية فقط، ولا تُكتب في أي ملف أو تقرير.

أكمل ما توقّف أو أوقفه

.\tools\Send-Campaign.ps1 -ClientId acme -RecipientsPath .\data\recipients.txt -Resume

راقب أثناء الإرسال

.\tools\Monitor-MailRotator.ps1 -ClientId acme -IntervalSeconds 5

٦. فلتر الصياغة

الرسالة تُرسَل كما هي، ما عدا الكلمات التي ترتبط ارتباطاً وثيقاً بالرسائل غير المرغوبة. الفلتر يبدّلها بمقابل محايد، ولا يمسّ الروابط ولا الاسم ولا النطاق:

free → complimentaryمجاني → مجاناً
click here → open the link belowاضغط هنا → افتح الرابط بالأسفل
guaranteed → assuredمضمون → مؤكَّد
act now → when you are readyافعل الآن → عندما تكون جاهزاً
  • في HTML لا يُلمس إلا النص بين الوسوم، فكل href وsrc تبقى كما هي بالحرف.
  • ٤٤ كلمة جاهزة، ويمكن للعميل إضافة كلماته: message.spamFilter.terms.
  • لإيقافه لعميل معيّن: "enabled": false.
  • عدد الاستبدالات يُعرض في التشغيل التجريبي ويُسجَّل في التقرير.

٧. الروابط المختصرة

عند تفعيل message.linkService يصير الرابط في الرسالة قصيراً على نطاقك، ويبقى الملف links.json هو المرجع الذي resolves الرابط:

"linkService": { "enabled": true, "baseUrl": "https://s.your-domain.com" }
الرابط في الرسالة : https://s.your-domain.com/s/Ab3xY9zZ?uid=<token>
الملف المنشور     : links.json  ←  { "Ab3xY9zZ": { "target": "..." } }

الكود ثابت لكل نسخة إعلانية، والرمز يميّز كل مستلم، والتحويل ينقل الزائر إلى صفحة الهبوط مع رمزه.
